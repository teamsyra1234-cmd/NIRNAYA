LULC Statistics as JSON/ Table

Introduction

Year wise LULC 250k statistics of years ranging from 2004-2005 to 2018-2019 for your Academic Research and Analysis. Gives you the Description of all the land use land cover types at the particular point(longitude,latitude) as a JSON.

Input URL

Display of Data for Single Year in Json Format


https://bhuvan-app1.nrsc.gov.in/api/lulc250k/curl_lulc250k_point.php?lon=77&lat=23&year=2004_05&token=xxxxxxxx

Display of Data for Multiple Years in Json Format


https://bhuvan-app1.nrsc.gov.in/api/lulc250k/curl_lulc250k_point.php?lon=77&lat=23&year=2004_05,2005_06&token=xxxxxxxx

Display of Data for All Years in Json Format


https://bhuvan-app1.nrsc.gov.in/api/lulc250k/curl_lulc250k_point.php?lon=77&lat=23&year=all&token=xxxxxxxx


Request Type

GET

Request Headers

Content-Type: Defines the type of content being sent to the API. It must be set to “application/x-www-form- urlencoded”.

Please note: sending any request without it or different than it would lead to a 400: Bad request.

Response Type

The API would return a JSON response.
Get Year Wise LULC stats (Description for every LU code) as GeoJSON.

Request Parameters

  • lon:Longitude
    Example: lon=80
  • lat:Latitude
    Example: lat=23
  • year:A single year or multiple years separated by comma or 'all' keyword for all years.
    Example 1: 2004_05 for single year
    Example 2: 2004_05,2005_06,2007_08 for multiple years
    Example 3: all for all years.
  • Token (Your API key for selected theme)
    Example: token=xxxxxxxx

    • Sample Output for all years

    • A JSON containing LULC stats.
