LULC Statistics as JSON/ Table

Introduction

State wise and District wise LULC 50k statistics of 2005-2006 and 2011-2012 years for your Academic Research and Analysis. Gives you the area of all the land use land cover types in that particular state/district as a JSON or as a table with percentage of total area covered by the LULC class in that particular state/district.

Input URL

https://bhuvan-app1.nrsc.gov.in/api/lulc/curljson.php

https://bhuvan-app1.nrsc.gov.in/api/lulc/curlpie.php


Request Type

GET

Request Headers

Content-Type: Defines the type of content being sent to the API. It must be set to “application/x-www-form- urlencoded”.

Please note: sending any request without it or different than it would lead to a 400: Bad request.

Response Type

The API would return a JSON response.
Get District LULC stats (area per LU Code) as GeoJSON/CSV.

Request Parameters

Note: Four digit: First two digit state code, next two for District code

  • Year
    • For statistics of 2005-2006 year (year=0506)
    • For statistics of 2011-2012 year (year=1112)

    • You can either give statcode or distcode in your get parameters. If both are given only distcode will be taken into consideration.

  • District Code
    Example: distcode=2301
  • State Code
    Example: statcode=AN
  • Token (Your API key for selected theme)
    Example: token=xxxxxxxx

Sample Output

  • A JSON containing LULC stats.
