LULC Area Of Interest Wise

Introduction

Area of Interest wise LULC stats for your academic reseach and statistical analysis. Gives you the area of all the land use land cover types in that particular AOI as a JSON, which can be exported to any Geospatial software for further analysis.Calculate LULC stats wherever you want in whatever area you want.

Input URL

https://bhuvan-app1.nrsc.gov.in/api/lulc/curl_aoi.php?geom=POLYGON((77.537826049804%2018.312927062987,77.539885986327%2018.279624755858,77.596190917968%2018.295417602538,77.537826049804%2018.312927062987))&token=xxxxxxxxxxxxxxx


Request Type

GET

Request Headers

Content-Type: Defines the type of content being sent to the API. It must be set to “application/x-www-form- urlencoded”.

Please note: sending any request without it or different than it would lead to a 400: Bad request.

Response Type

The API would return a JSON response.
Gives the area of each type of LandUse code for the states present in the area of interest. For the given theme accordingly.

Request Parameters

Note: Geometry has to be provided as WKT.

  • geom
  • token (you api key for selected theme)

Sample Output

  • Null if no data is available in database.
