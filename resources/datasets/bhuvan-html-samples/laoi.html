LULC Area Of Interest Wise

Introduction

Area of Interest wise LULC stats for years ranging from 2004-2005 to 2018-2019 for your academic reseach and statistical analysis. Gives you the area of all the land use land cover types in that particular AOI as a JSON or in form of Bar Chart as choosen by the user, which can be exported to any Geospatial software for further analysis.Calculate LULC stats wherever you want in whatever area you want.

Request Type

GET

Request Headers

Content-Type: Defines the type of content being sent to the API. It must be set to “application/x-www-form- urlencoded”.

Please note: sending any request without it or different than it would lead to a 400: Bad request.

Response Type

The API would return a JSON response.
Gives the area of each type of LandUse code for the states present in the area of interest. For the given theme accordingly.

Request Parameters

Note: Geometry has to be provided as WKT.

  • polygon:in WKT format
  • year:A single year or multiple years separated by comma or 'all' keyword for all years.
    Example 1: 2005_06 for single year
    Example 2: 2005_06,2006_07,2007_08 for multiple years
    Example 3: all for all years.
  • option: Either json or chart. Example: option=json
  • token (get Access token for LULC AOI Wise)
